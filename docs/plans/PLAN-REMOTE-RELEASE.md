# PLAN — Audiout Remote release

*2026-09-05, revised 2026-09-06 after three design reviews and five design briefs in `dev/notes/remote-release-2026-09-05/`. Target: Audiout Remote submitted to App Store review by 3 October 2026, a matching Mac release, one audiout-shared tag pinned in both, the website flipped the day the store link exists. Decisions live in `docs/adr/0001-remembered-offset-on-reconnect.md`, `audiout-shared/docs/adr/0001-quieter-sweeps.md`, and the glossary `audiout-shared/CONTEXT.md`. Research: `dev/notes/bt-latency-stability-research-2026-09-05.md`.*

Four repos: **shared** (audiout-shared), **phone** (audiout-remote), **mac** (this repo), **site** (Audiouter Website), plus the **server** (Audiout License Server). Paths are relative to each repo's root. Every task names the brief that is its spec; the builder reads the brief, not this table, for copy and layout.

## Decisions

| # | Decision |
|---|---|
| D1 | Scope: phone first launch through first measurement, the sync sheet, the Mac's invites, the website, the listing. All of it gates submission except the crowd registry. |
| D2 | Buyer is Mac-first. The listing says the phone needs Audiout for Mac. |
| D3 | Lead claim everywhere: measured with your iPhone. Airfoil and SoundSource measure nothing; Airfoil's free remote and Bluetooth output are parity, never pitched as advantages. The Mac's click wizard stays as "Align by ear". The phone measures Bluetooth speakers only, and every claim says so except the home page headline (assumed, unanswered). |
| D4 | Name: Audiout Remote. Subtitle: "The remote that tunes your speakers." Closes T23 of the companion plan. The intro wordmark reads Audiout Remote; the gate's button reads "Find my Mac". |
| D5 | Intro: three cards, the field and the mark still, only the copy pages. Next, Next, Find my Mac on one gold capsule; Skip as the quiet action on cards 1 and 2. Spec: `shape-first-launch.md`. |
| D6 | Demo ships in release, reachable from the checklist row after the 8 s timeout, a labelled strip above the tabs; "Your Mac is here" joins it when a real Mac appears and opens the Switch Mac sheet, never connects on its own. Settings' exit button loses its debug guard and reads "Leave demo". |
| D7 | Sound only from the speakers being synced. Verdict plays the before-and-after unprompted. The demo stays silent: the phone has no audio path and the demo row promises nothing plays out loud; the sheet's swap and hold run on the phone's own clock. Sweeps: 80 ms fades in the shared package, 6 dB lower staging level on the Mac (shared ADR 0001, amended). |
| D8 | Haptics: measurement lands, connected. Level-drag haptics stay as shipped. Motion: rings converge on the Mac's name at arrival, the field swells once with the sweeps, rings converge at the before-to-after swap. Reduce Motion: no ring travel, swells allowed. Spec: `shape-first-launch.md`, `shape-sync-sheet.md`. |
| D9 | Four pages before Measure: silent speaker, microphone, one merged "where you listen" page with the clicks on, Hold still. Measure is live whenever both speakers play; the clock verdict only chooses the footnote and the label. Verdict copy speaks in audibility bands (under 10, 10 to 40, 40 and over), milliseconds under Details. |
| D10 | Reconnect: the Mac publishes status tuned with source fromLastTime; a first pass publishes status stale with source firstPass. Re-measurement replaces at 10 ms or more, the user is told at 40. The re-check offer is the invite card reworded, opening the sheet; no run ever starts without the Hold still page. |
| D11 | One settle record per link-up from the renamed timing module: speaker key (per-install index, never the device UID), codec (nil until proven), jump count, seconds to settle, offset in force, source. Local log always; release event through the Mac's existing opt-in analytics. Crowd registry deferred. |
| D12 | Phone: Apple crash reports plus PostHog, anonymous, on by default, one opt-out switch. Mac: analytics stay opt-in, off by default. The Mac sends a join id on `welcome` so a funnel can link the two devices; it is a separate random id kept in the Mac's settings, never the Mac's own analytics id, because the Mac's analytics are opt-in and the phone's are on by default. Event names follow the Mac's `area:action` form and live in one shared data-only doc. |
| D13 | Reliability and consistency as one component per pattern: `EmptyStateView` (reconnecting, not connected, nothing here), `GoldCTALabel` with two shapes replacing three faces, `TextAction`, `StatusBanner` with a shell top slot. Banner rule: a fact with a duration is a banner at the top, an answer to a tap is a toast at the bottom. Spec: `shape-phone-system.md`. |
| D14 | English only, strings in a String Catalog. |
| D15 | The Mac invites the phone through one QR-and-link view hosted three ways: a popover from the untuned Bluetooth chip offering "Measure with your iPhone" then "Align by ear", a row under the Allow switch, and a seventh first-run card (moss green, contrast measured by the builder). The licence email and `/thanks` carry a fourth setup step. Every QR encodes `audiout.app/remote`, a page in both states; once live it carries the store badge and Apple's Smart App Banner. Spec: `shape-mac-invites.md`, `shape-site.md`. |
| D16 | Wire: `groups` stays. `AlignmentState` gains `source` (measured, firstPass, fromLastTime, byEar); `alignmentApplied` carries it too. `AlignmentThresholds` (10, 40) live in the protocol so both peers read the same numbers. No protocol version bump. |

## Owner-only prerequisites

- Install an iOS simulator runtime (`xcrun simctl list runtimes` is empty on Xcode 27.0); the phone's tests compile but cannot run.
- Set the phone's `DEVELOPMENT_TEAM` (`project.pbxproj:423`) or pass it per `AGENTS.md:118-124`; stand up TestFlight per `docs/companion-app-store.md:119-133`.
- Apply licence-server migration `0005_remote_signups.sql` to production D1. `scripts/release.sh:77-93` refuses to cut a Mac release while it is unapplied.
- Run one Bluetooth connection with `log stream --predicate 'process == "bluetoothaudiod"'` open and paste the codec line into T15, or strike codec from the settle record.
- Reconnect a Sonos Move 2, the Sony, and a third speaker twenty times each before T23.
- Answer the Bluetooth-scope question in D3 if the default is wrong.
- Confirm two assumptions in `shape-phone-system.md`: "Diagnose" becomes "Details" on the failed row, and Apps' empty state gains an "Add app" button.
