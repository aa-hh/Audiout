## Goal

Give every wired Core Audio output on the Mac (built-in speakers, headphone jack, USB, HDMI/DisplayPort, Thunderbolt) its own `Device` row of a new kind `.wired`, keyed by Core Audio UID, fed by a new HAL-only enumerator through the same `deviceAdded`/`deviceUpdated`/`deviceRemoved` flow Bluetooth rows use. The row that IS the current system default output is hidden (it is what "This Mac" already plays through), and the hidden one swaps when the default changes. This is the model + enumeration layer only; tickets 03 (sink), 04 (popover placement, deselect edge, drawer) and 05 (routing) build on it. The mock backend gets two wired fixtures so `run-app.sh` shows the rows offline.
