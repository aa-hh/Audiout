# J, sidebar refinement

**Groups: "In the Mixer" over "Hidden unless playing".** Both stay true for every row. Rejected: "Other speakers" (never mentions the Mixer); "Not in the Mixer" (false while playing); "Nearby" (false for an unavailable speaker).

**Moving.** Right-click › Hide from Mixer / Show in Mixer (how Mac sidebars act on rows; works with keyboard, VoiceOver, multi-select). Dragging onto the other header also works (native to NSOutlineView). No hover button: source lists have none.

**Away option.** Right-click › "Keep in Mixer when unavailable", a checkmark, first group only. Ticked means Always.

**Rows.** Fixed 36 pt, two lines. Alphabetical, This Mac first; a hidden speaker that plays stays put with gold "Playing". Long names truncate.

**New speakers land in "In the Mixer".** The Mixer can't pick a hidden speaker, so a new HomePod would be unplayable.

**2 vs 15.** Two: one header. Fifteen: the list scrolls; only the second header folds (stock hover chevron).

**Strings.** Captions: This Mac, Ready, Playing, Unavailable, ⚠ Can't be found. Menu: Hide from Mixer · Show in Mixer · Keep in Mixer when unavailable · Add scene from "Name"… · Forget "Name"… (unfindable only). Multi: Hide 3 speakers from Mixer · Show 3 speakers in Mixer (both when split) · Add scene from 3 speakers… · Forget 2 speakers…. Alert: Forget "Study"? / Audiout removes it from 2 scenes and stops listing it. / Forget Speaker · Cancel.

**Follow-up.** The plate's "yours / other" and the detail's "Available" must follow these words.
