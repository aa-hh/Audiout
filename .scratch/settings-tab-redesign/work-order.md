# Work order: Settings tab redesign (direction D revised, with colour)

### Goal

Rebuild the Settings screen so its sidebar tells the user what is set before any click: five two-line source-list rows (General, Audiout Remote, Appearance, Audio, License), each with a live readout under its name, and every pane opening with the Speakers page header (bare glyph, no icon well) over `ListRowView` rows on `GroupedSectionView` cards, with License in a recessed well. Buy Audiout turns gold (`ProminentButton`) in the trial and unregistered states; the sidebar glyph and License header glyph take the `ring` token only while the user must act. Everything else stays neutral and stock. This is for a general Mac user who opens Settings mid-task to check one fact or flip one switch. All work stays uncommitted.

- Equalizer controls open editors; rows hold no tone. Names reserve equal accessory space.
- Test hooks use the real action path.
- Reusable views treat `NSApp` as optional.
- Permission prompts suspend transient dismissal across pin changes; restore manners before raising windows.
